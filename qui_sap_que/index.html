Configuració del Concurs

Com aconseguir una API Key gratuïta en 1 minut:

  1. Fes clic per obrir Google AI Studio.
  2. Inicia sessió amb qualsevol compte personal o professional de Google (Gmail).
  3. Prem el botó blau "Get API key" (es troba a dalt a la cantonada esquerra).
  4. Fes clic a "Create API key", copia el codi llarg generat (comença per AIzaSy) i enganxa'l aquí a dalt.
